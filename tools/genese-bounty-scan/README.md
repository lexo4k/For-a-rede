# GÊNESE: Public Bounty Scanner

Scans public GitHub issues for open-source tasks that mention bounties or payment amounts.

## Run
```bash
python -m unittest -v
python genese_bounty_scan.py
```

## Important
- A listed reward is **unverified**, not money already earned or guaranteed.
- The script never claims a task, comments, submits code, logs into payment accounts, or transfers funds.
- A human must inspect the original task, confirm it is still available and funded, understand requirements, and obtain assignment before doing work.
- This tool does not connect to Mercado Pago and cannot create income or payments by itself.
