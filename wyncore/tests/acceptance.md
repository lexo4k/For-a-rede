# WYNCORE acceptance checklist

- [ ] Navigation opens all five sections.
- [ ] Opportunity form rejects empty required fields and non-HTTPS links.
- [ ] New opportunity is persisted locally after reload.
- [ ] Opportunity can be added to task tracking only once.
- [ ] Task status changes persist after reload.
- [ ] Estimated, confirmed, and received totals remain separate.
- [ ] CSV export contains task title, source, announced value, and status.
- [ ] No UI claims that local records are verified income or withdrawable balance.
- [ ] No payment, deposit, upgrade, referral, or transfer action is exposed in prototype.
- [ ] Backend authentication and authorization are required before production deployment.
